# ViT PyTorch Training

## 1. Install Dependencies
Install all required packages:
```bash
pip install -r requirements.txt
```

## 2. Check Requirements
Verify dependencies are installed:
```bash
pip list
```

## 3. Test with One Epoch
Run a quick test for one epoch:
```bash
python train_local.py --epochs 1
```

## 4. Test Parameters with 100 Epochs
Run the full 100 epoch training:
```bash
python train_100_epochs.py
```
